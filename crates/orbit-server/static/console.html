Propose an Orbit task status change

Submit a pending proposal for separate approval. An opt-in authorized agent worker must be running to apply approved changes to its local Orbit database. Browser changes are not direct edits.

Propose a new project task

Requires administrator approval before a worker creates the task. Each proposal has a stable task ID for retry reconciliation.

Propose a habit completion

Records a specific completion timestamp after separate administrator approval. Proposal identity prevents duplicate occurrences on reconciliation.

Propose a metric observation

Requires a configured local metric target and administrator approval. Repeated timestamp/value pairs are idempotent; conflicting values fail closed.

Agent proposals requiring approval

Review intent, target and payload before authorizing. Approved task-status, project task-creation and habit-completion proposals can execute through an opt-in worker; habit and metric proposals execute through allowlisted workers.
