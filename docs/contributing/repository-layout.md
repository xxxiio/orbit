# Repository layout

- `crates/`: Rust application, storage, client, interfaces, and optional server.
- `blueprints/`: sample/declarative workflow packages.
- `deploy/server/`: self-hosting assets and optional Python worker implementations.
- `scripts/`: active installers, release acceptance tools, and operational utilities only.
- `tests/`: maintained capability-based contracts, acceptance, and packaging checks.
- `docs/getting-started/` and `docs/guides/`: user workflows.
- `docs/reference/`: interface references.

GetDone and Git are sources of development history; do not add milestone-specific READMEs, duplicate progress records, or numbered source-text test scripts.
