# Task: M33 corrective — Milestone unification, task creation UX, unified Tasks workspace

## Objective

Correct the rejected Epic-based M33 design: make Milestone the only project
work-grouping entity, remove Epic, let users configure a task fully before creating
it, place List/Board/Backlog under one Tasks tab, make the Board compact and
readable, and rebuild the Roadmap around Milestones. Keep the retained typography
and authentication work, and add the explicit opt-in local-trusted browser mode.
Complete the milestone only after a human has reviewed the running app and the
representative captures.

## Specification

- Epic is removed as a create/edit/filter/column/roadmap concept; existing local
  Epic data converts once into Milestones without losing task identity or an
  existing milestone assignment.
- One canonical Milestone aggregate carries description, status, optional
  priority/owner/start/target, Tasks and supported Workflow Work Items, derived
  progress, blockers, activity and safe delete/move guards.
- A fully configured task is created in one accepted operation; quick capture stays
  lightweight and retries are idempotent.
- One Tasks tab presents List, Board and Backlog through URL-backed views with
  shared filters; legacy links redirect.
- The Board is compact by default with title, priority, deadline and blocked cues,
  persisted density and authoritative movement.
- The Roadmap is one Milestone hierarchy with duration bars, checkpoint markers,
  unscheduled work, child task windows and blocked/dependency cues.
- `ORBIT_AUTH_MODE=local-trusted` is an explicit opt-in, refused on every
  non-loopback bind, leaving privileged surfaces separately authenticated.
- Human review is required before completion; automated screenshots and DOM
  assertions are not approval.

## Ordered plan

1. Consolidate Milestone authority, Work Item membership, Epic conversion and
   removal, and rich atomic task creation (Rust).
2. Add the additive web API for rich milestones and full task creation.
3. Build the unified Tasks workspace, compact Board, full create dialog, milestone
   detail and the Milestone Roadmap.
4. Remove the remaining Epic API/UI/tests and reconcile navigation and terminology.
5. Add the opt-in local-trusted authentication mode with its guards, tests and
   documentation.
6. Run browser acceptance, persistence restart, captures, documentation and the
   human review handoff; record the human acceptance and close M33.
